## ✦ Creative Direction & Visual Identity

FII Studio merges cinematic realism, sophisticated minimalism, real-time 3D WebGL graphics, and typographic artistry.

- **Color Architecture:**
  - `Void Black` (`#040406` / `#08080C`): Deep cosmic background preventing chromatic clutter.
  - `Liquid Chrome` (`#E4E8EE` to `#8A94A6`): Polished physical metallic reflections with high specular iridescence.
  - `Electric Lime` (`#CCFF00`): Kinetic accent color symbolizing computational energy and forward momentum.
  - `Warm Ivory` (`#F5F3EF`): Humanist typography ensuring effortless readability.
- **Brand Monogram:** Custom sculptural geometric **FII** emblem representing structural permanence and digital fluidity.
- **Sound Design:** Fully synthesized Web Audio API soundscape (subtle micro-clicks, resonant hovers, harmonic chords, and warp swooshes—zero external audio file dependencies).

## ✦ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/deepeshpankaj01/fii-studio.git
cd "Fii studio"

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ✦ Production Build & Deployment

```bash
# Build optimized static and server bundles
npm run build

# Start production server
npm run start
```

### Deploying to Vercel
This project is configured out-of-the-box for **Vercel**:
1. Push this codebase to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. The framework preset will automatically detect Next.js with zero configuration needed.
